# SAV – Sistema de Gestão Varejista | AFLA Sistemas

Site estático (HTML, CSS e JavaScript puros, sem build) para divulgar o SAV.

## Estrutura

```
index.html          página principal
css/style.css       estilos
js/main.js          menu do celular e links do WhatsApp
assets/images/      logotipos
```

## Antes de publicar

1. Troque o número em `js/main.js` (`WHATSAPP_NUMERO`).
2. Procure por `[PREENCHER]` e `[CONFIRMAR]` no `index.html` e complete os textos.
3. Coloque capturas de tela do SAV em `assets/images/` no lugar do espaço reservado.

## Ver localmente

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

Envie os arquivos para um repositório e ative **Settings → Pages** apontando para a branch principal, pasta raiz.
